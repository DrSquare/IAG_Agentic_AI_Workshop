# Board Paper Standard

Reference documents (SharePoint > Board): Board Paper Standard.docx and Risk Appetite Statement - Summary.docx. If they differ from this skill, the documents win.

## Page 1 must show
- Decision sought, starting "The Board is asked to..."
- Recommendation and why.
- Total cost including contingency and run costs; benefits; payback; NPV.
- Top three risks, each mapped to the Risk Appetite Statement.
- Options considered, including "do nothing".

## Numbers
- Every benefit needs a baseline, stated assumptions and a sensitivity range (downside / base / upside).
- Figures in the paper must match the named source model (for example business-case-model.xlsx). Check totals, payback and ratio impacts against it.
- External benchmarks need a source and date. Vendor claims must be labelled as vendor claims.

## Risk and regulatory language
- Use Risk Appetite Statement terms ("within appetite", "approaching tolerance").
- Name the APRA and ASIC obligations touched: CPS 230 (operational risk, material service providers, exit plans), CPS 234 (information security), claims-handling obligations, privacy.
- State customer impacts, especially any automated decision that declines or reduces a claim (our appetite requires human review).
- State workforce impacts in the body, not only in an appendix.

## Review output
Verdict (Ready / Ready with changes / Not ready) · top 5 fixes in priority order · conflict log (issue | view A | view B | resolution) · page-referenced comments. Critique only; don't rewrite the paper.
