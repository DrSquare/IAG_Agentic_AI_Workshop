# Insurance KPI definitions

Use these definitions whenever you extract or calculate figures. If a report defines a measure differently, use the report's figure, note the difference, and never mix definitions across years.

| KPI | Definition |
|---|---|
| GWP | Gross written premium |
| Insurance revenue | AASB 17 insurance revenue |
| NIR | Net insurance revenue: insurance revenue less reinsurance expense |
| Net claims ratio | Net claims expense / NIR. Split into attritional, natural hazard and prior-year reserve releases where disclosed |
| Expense ratio | Underwriting expenses / NIR. Check notes for reclassifications between years |
| COR | Net claims ratio + expense ratio |
| Insurance profit | NIR - net claims - underwriting expenses |
| ITR | (Insurance profit + investment income on technical reserves) / NIR |
| Underlying ITR (calc) | ITR excluding reserve releases above the "normal" level the company states; label as calc |
| Natural-hazard variance | Natural-hazard costs minus allowance |
| Capital | PCA coverage multiple (or CET1 multiple) against the stated target range |
| Payout ratio | Dividend per share / earnings per share, against the stated target range |

## Rules
- Every figure carries its page reference.
- Mark anything you calculated as "calc" and show the formula once.
- If a figure is not in the source, write "not disclosed". Never estimate silently.
- Check that headline figures (highlights pages) match the financial statements; flag any mismatch.
- Don't round away movements under 0.5 percentage points.

## Role lenses for dashboards
- CEO: five headlines, strategy progress, guidance, questions for the Board.
- CFO: NPAT, ROE, capital vs target, investment income, payout ratio, reserve releases.
- Chief Underwriting Officer: COR and ITR by segment, attritional vs natural hazard vs reserve releases, rate vs volume.
- Chief Claims Officer: claims ratio drivers, natural-hazard cost vs allowance, claims handling expense, cycle time.
